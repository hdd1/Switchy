# CLAUDE.md — Switchy

Общение, комментарии к коду и сообщения коммитов — на русском.

Switchy — личная утилита для macOS (строка меню): ручной/умный перевод текста между раскладками
EN/RU/UA, прямые хоткеи раскладок, память раскладки по окнам, история буфера обмена.

- Что делаем — `SPEC.md`; этапы — `PLAN.md`.
- Swift Package (без `.xcodeproj`), Swift 6, macOS 15+, AppKit + SwiftUI. Без App Sandbox.
- Сборка и запуск: `scripts/build-app.sh --run` (собирает `build/Switchy.app`, подписывает
  «Apple Development» — подпись стабильная, права TCC не слетают).
- Тесты (когда появятся): `swift test` — только чистая логика (маппинг раскладок, буфер, детектор).
- Поведение с клавиатурой проверяет пользователь руками — перехват событий автотестами не покрыть.
- Коммитить — только по просьбе пользователя.
